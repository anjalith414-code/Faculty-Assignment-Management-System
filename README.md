💫 About the Project

Assignment Galaxy is a modern, interactive, and visually appealing web application designed to simplify faculty assignment management.

It helps faculty members track student submissions, manage assignment records, and monitor progress through a single dashboard.

🎯 Our Mission: Make academic assignment tracking easier, faster, and more organized.

⸻

✨ Features That Shine

Feature	Description
🎨 Modern UI	Colorful interface with attractive styling
📚 Subject Management	View multiple subjects and faculty details
👩‍🎓 Student Register	Access student roll numbers and records
✅ Submission Tracking	Mark assignments as submitted
📅 Date Tracking	Record assignment submission dates
↩️ Undo Option	Reverse a submission status when needed
🔍 Search & Filter	Find students and filter records
📊 Dashboard Statistics	View assignment progress at a glance
📁 CSV Export	Export submission records
💾 Local Storage	Retain data in the same browser

⚠️ Current Limitations

* Submission records are stored in the browser’s local storage.
* Data does not automatically synchronize between devices.
* A backend database and authentication system are not currently included.

💖 Why Assignment Galaxy?

“Turning everyday academic tasks into a simpler digital experience.”

Assignment Galaxy aims to reduce manual record-keeping and make assignment submission tracking more convenient for faculty members.
